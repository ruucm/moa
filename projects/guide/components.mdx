## Figure — One Image, Click to Zoom

`wide` lets the image breathe past the reading column. Every image in a document opens in the
same viewer, so ← / → step through all of them — no extra markup needed.

```mdx
<Figure src="/my-project/keyart.jpg" cap="Adopted take. The censer and the phoenix read together." wide />
<Figure src="/my-project/clip-01.mp4" cap="Clip 1" video />
```

<Figure src={placeholder} cap="Captions sit under the image. Click it (or press Enter on it) to open the viewer." wide />

Props: `src` · `cap` · `alt` (defaults to `cap`) · `wide` · `video` · `full` (a larger source to
show in the viewer) · `zoom={false}` to opt out.

## MediaGrid — Image/Video Grid

Grid images are click-to-zoom as well.

```mdx
<MediaGrid cols={3} items={[
  { src: '/my-project/still-01.png', cap: 'Shot 1' },
  { src: '/my-project/clip-01.mp4', cap: 'Clip 1', video: true },
]} />
```

## Images in Markdown

`![caption](/my-project/still-01.png)` is click-to-zoom too — the alt text becomes the viewer
caption. A raw `<img>` tag written in MDX is *not* (MDX leaves literal JSX alone), so reach for
`Figure` or Markdown syntax when you want the viewer.
