# Component Catalog

All of these work in MDX with no imports. Everything below is rendered live.

## Stats — Key Metrics

```mdx
<Stats items={[
  { label: 'Final cut', value: '2:30.4', sub: '27 clips · 1080p' },
  { label: 'Total cost', value: '$156.80', accent: true, sub: 'P2+P2.5+P3' },
]} />
```

<Stats items={[
  { label: 'Final cut', value: '2:30.4', sub: '27 clips · 1080p' },
  { label: 'Re-rolls', value: '6', sub: '4 of 13 clips' },
  { label: 'Total cost', value: '$156.80', accent: true, sub: 'P2+P2.5+P3' },
]} />

## DataTable — Measured Numbers

Rows whose first cell is `Total` are highlighted automatically.

<DataTable
  cols={['Stage', 'Clips', 'Cost', 'Re-rolls']}
  rows={[
    ['P1 pilot', '4', '$12.80', '1'],
    ['P2 full run', '13', '$41.60', '3'],
    ['Total', '17', '$54.40', '4'],
  ]}
  note="* Use the note prop to add a footnote under the table."
/>

## Checks — Checklist

Items starting with `✅ ` are rendered as done.

<Checks items={[
  '✅ Script pronunciation pass',
  '✅ Pilot 4 clips passed QC',
  'Generate remaining 13 clips',
  'Final assembly + numeric verification',
]} />

## Issues — Issue Tracking

`sev`: `high` (top priority) · `warn` (caution) · `done` (resolved)

<Issues items={[
  { sev: 'high', t: 'Lip-sync drift', d: 'clip 07 · 0.3s — needs a re-roll' },
  { sev: 'warn', t: 'Background tone variance', d: 'clip 11 · coverable with color grading' },
  { sev: 'done', t: 'Boundary freeze frames', d: 'all 26 boundaries removed (v5)' },
]} />

<Timeline items={[

## Callout — Highlight Box

`type`: `info` · `warn` · `success` · `danger`

<Callout type="warn" title="Caution">
Each re-roll costs $3.20 per clip. Pass the QC gates first, then move on to full generation.
</Callout>

<Callout type="success" title="Passed">
All 5 human-ear proxy gates passed — clear to proceed to assembly.
</Callout>

## Badge — Status Badge

`tone`: `live` · `wait` · `done` · `muted` — <Badge tone="live">In progress</Badge> <Badge tone="wait">Waiting</Badge> <Badge tone="done">Done</Badge> <Badge tone="muted">Archived</Badge>
