# Slides

A deck is an ordinary MDX document. Every slide below is a card you can read and edit in place:
save the file and the open page updates within seconds — even while you are presenting.
**Present** shows the slides one at a time, full screen.

## Writing a deck

```mdx
<Deck title="Week 2" footer="Course · Week 2">

<Slide kicker="Part 1" title="Prompt blocks" sub="Seven blocks, one sentence" time="5:00–8:00">

- Markdown works here
- **Bold**, `code` and numbered lists too

<Notes>
What to say on this slide.
</Notes>
</Slide>

<Slide layout="split" title="Open and run" timer={4} image="/my-project/expected.jpg" cap="Expected result">

Press **Run** without changing anything.

</Slide>

</Deck>
```

Leave a blank line after an opening tag and before a closing tag so the Markdown inside is read as Markdown.
Anything in a deck that is not a `<Slide>` — a `## heading` between parts, a paragraph — shows in the
document only, and headings there appear in the page outline.

### `Deck`

| Prop | Meaning |
| --- | --- |
| `title` | Shown in the deck's toolbar and read out by screen readers |
| `footer` | Small text in the bottom-left corner of every slide except covers |
| `aspect` | `16:9` (default) · `16:10` · `4:3` |
| `id` | Prefix for slide links, `slide` by default (`#slide-12`). Give each deck its own when a page has two |

### `Slide`

| Prop | Meaning |
| --- | --- |
| `title` · `sub` · `kicker` | Title, subtitle and the small label above the title. Break a line with `title={'One\nTwo'}` |
| `layout` | `default` · `split` (text left, picture right) · `cover` · `section` · `statement` |
| `image` | A picture: below the text (default), on the right (`split`), or full-bleed behind the text (`cover`, `section`, `statement`). Add `video` for a video file |
| `fit` · `position` · `cap` · `alt` | `fit="cover"` crops to fill (`position="top"` keeps the top), `cap` labels the picture, `alt` describes it |
| `split` | Width of text and picture in a split slide, `5:7` by default |
| `tag` · `tone` | A status tag in the top-right corner. `tone`: `accent` · `success` · `warning` · `danger` · `info` · `muted` |
| `timer` | Minutes for an exercise countdown. Click it, or press **T** while presenting |
| `time` | When the slide happens in the talk (`12:00–15:00`). Shown in the document and with the notes |
| `mark` | A large faint number or word behind a section slide |
| `id` | A stable link name (`id="intro"` → `#intro`) that survives slides being added before it |

### Inside a slide

- `<SlideGrid items={[{ src, label, sub, tone }]} note="…" />` — pictures with labels in the space left on
  the slide. Without `cols` the grid tries every column count and keeps the one that makes the pictures
  largest; `cols={4}` fixes it. Pictures are never cropped unless `fit="cover"`. `ratio="3/4"` states their
  shape so the slide is laid out before they load. `src` can be a list for a pair side by side, and
  `label` and `sub` on the grid itself add a row heading, so two grids stack as two labelled rows.
- `<SlideChecklist items={['…']} />` — items the room ticks off. Items starting with `✅` begin ticked.
- The shared report components (`Callout`, `Stats`, `DataTable` …) and Markdown tables work as well.

## Presenting

**Present** in the deck's toolbar starts from the slide you are looking at; the ▶ under a slide starts
from that slide. The page stays in presentation mode while the file is saved and reloaded.

| Key | Action |
| --- | --- |
| → · Space · PgDn · click | Next slide (click the left quarter to go back) |
| ← · PgUp | Previous slide |
| Home · End | First · last slide |
| 12 Enter | Go to slide 12 |
| F | Full screen |
| N | Speaker notes |
| O | All slides |
| T | Start or pause the timer (Shift+T resets) |
| C | Tick the next checklist item |
| B · . | Blank the screen |
| Esc | Close a panel, then end the presentation |
